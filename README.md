# Sky-Phys Project: 高空物理數據觀測站

這是一個基於 Raspberry Pi 5 與 RTL-SDR v4 的科學實作專案。透過接收飛機廣播的 ADS-B (Automatic Dependent Surveillance-Broadcast) 訊號，我們利用空氣動力學公式，將每一架經過新竹上空的客機轉化為「高空探空儀」，即時觀測大氣剖面。

## 📁 專案架構與數據管理

本專案採用數據分區 (Data Partitioning) 策略，確保系統可 24/7 長期運作而不受單一檔案過大影響，並支援自動歸檔：

- **`scripts/`**:
    - `recorder.sh`: 背景數據採集器，自動按日歸檔，具備單一實體執行保護。支援採集 **17** 種遙測數據 (含 TAS, Mach, 垂直升降率, 機型等)。
    - `dashboard.py`: 核心分析引擎 (Python 版)，支援 **滾動時間窗口 (Rolling Window)** 分析 (預設 24 小時)，解決跨日數據斷層問題。
    - `dashboard.R`: **進階分析與繪圖引擎 (R 版)**，提供更精美的 ggplot2 視覺化圖表，支援物理註解字幕、統一排版樣式 (`theme_skyphys`) 與 **時段過濾功能** (`--start_hour`, `--end_hour`)。自動生成數據摘要報告 (`report_YYYY-MM-DD.txt`)。
    - `mapper.py`: 地理空間分析，支援自訂時窗 **或指定日期** 軌跡繪製，產出航跡熱圖與 **分層高度航線圖**。
    - `update_all.sh`: 一鍵自動化更新腳本，支援帶參數指定回推時間 (如 `./update_all.sh 12`)，並負責 **每日報告歸檔**。
    - `archive_yesterday.sh`: **強力歸檔工具**，自動運算昨天的日期，執行完整日曆天 (00:00-24:00) 分析並歸檔至 `daily_archive/`，適合排程執行。
- **`logs/`**: 儲存 `adsb_YYYY-MM-DD.csv` 格式的日誌檔案。
- **`reports/`**:
    - **`daily_archive/`**: 按日期自動歸檔的歷史圖表與數據報告。
    - `plot_*.png`: 各類物理分析圖表 (最新版)。
    - `sky_phys_map.html`: 互動式收訊熱圖。
    - `sky_phys_map_altitude.html`: **新功能** 高低空分層航線互動地圖。
    - `observation_summary.txt`: 自動生成的 Markdown 格式數據報告 (含西風帶指標、飛行性能極值)。

## 🧪 物理運算核心

專案核心在於利用飛機廣播的真速 ($TAS$) 與馬赫數 ($M$)，在不依賴外部氣象站的情況下，自行推算高空環境物理量：

### 1. 靜溫 (OAT) 與聲速 ($a$) 推算
根據航空聲學公式，音速是溫度的函數。我們透過反推得知當下高度的溫度，並排除解碼異常值：

$$a = \frac{TAS}{M}$$

$$T_{^\circ\text{C}} = \left( \frac{a}{38.945} \right)^2 - 273.15$$

### 2. 順/逆風分量 (Wind Component)
透過地速 ($GS$) 與真速 ($TAS$) 的向量偏差，並利用航向 (`track`) 區分東西行航班，觀測高空風場的推力：

$$\text{Wind Component} = GS - TAS$$

### 3.幾何高度異常 (D-Value)
這是氣象學上用來觀察高空高/低壓系統的關鍵指標。
*   **公式**: $$D = \text{Alt}_{\text{Geom}} - \text{Alt}_{\text{Baro}}$$
*   **數據源**: `Alt_Geom` (GPS 幾何高度) vs `Alt_Baro` (標準氣壓高度, QNE 1013.25hPa)。
*   **物理意義**:
    *   $D > 0$: 真實高度高於壓力高度 $\rightarrow$ 空氣密度低 $\rightarrow$ **暖空氣 (高壓脊)**。
    *   $D < 0$: 真實高度低於壓力高度 $\rightarrow$ 空氣密度高 $\rightarrow$ **冷空氣 (低壓槽)**。

### 4. 比能量高度 (Specific Energy Height, $E_s$)
將飛機視為一個質點，計算其總機械能 (Total Energy) 隨高度的變化，反映能量管理效率。
*   **公式**: $$E_s = h + \frac{TAS^2}{2g}$$
*   **單位轉換**:
    *   $h$: 高度 (公尺, $ft \times 0.3048$)
    *   $TAS$: 真速 (公尺/秒, $knots \times 0.5144$)
    *   $g$: 重力加速度 ($9.80665 m/s^2$)

### 5. 空氣密度 ($\rho$)
利用理想氣體方程式，結合標準大氣壓模型與實測溫度，推算當下空域的真實空氣密度。
*   **公式**: $$\rho = \frac{P}{R_{\text{specific}} \cdot T}$$
*   **變數說明**:
    *   $P$: 靜壓 (Pa)，由標準大氣公式 $P = P_0 (1 - \frac{L \cdot h}{T_0})^{\frac{gM}{RL}}$ 近似推算。
    *   $T$: 靜溫 (K)，由我們反推的 $OAT$ 轉換而來 ($^\circ\text{C} + 273.15$)。
    *   $R_{\text{specific}}$:乾燥空氣氣體常數 ($287.058 J/(kg \cdot K)$)。

### 6. 飛機雲生成機率 ($P_{contrail}$)
基於 **Appleman Criterion (1953)** 的簡化模型，預測凝結尾 (Contrails) 的生成。
*   **原理**: 引擎排出的高溫水氣與環境冷空氣混合。當混合氣體的蒸氣壓超過飽和蒸氣壓時，便會凝結。在極低溫下 ($<-40^\circ\text{C}$)，凝結水滴會瞬間凍結成冰晶，形成持久的飛機雲。
*   **判斷標準** (因缺乏高空濕度數據，採用 **溫度主導法**):
    *   **$T > -40^\circ\text{C}$**: **不可能生成** (No Contrails)。即使凝結也因溫度過高而無法凍結，迅速蒸發。
    *   **$-40^\circ\text{C} \ge T \ge -50^\circ\text{C}$**: **可能生成** (Possible)。取決於當下大氣濕度 (RH)。
    *   **$T < -50^\circ\text{C}$**: **極可能生成且持久** (Probable/Persistent)。在此低溫下，引擎排出的水氣足以達到冰飽和 (Ice Saturation)。

## 進階觀測指標

本專案不僅紀錄路徑，更具備以下氣象研究指標：

- **對流層頂 (Tropopause) 預測**: 自動偵測溫度隨高度停止下降的轉折點，定位對流層邊界。
- **氣溫直減率 (Lapse Rate)**: 計算每上升 $1,000\text{ ft}$ 的溫度變化，並對比「清晨、午後、深夜」的時段差異。
- **噴射氣流 (Jet Stream) 分析**:
    - **警報**: 當高空風分量超過 $100\text{ knots}$ 時自動標註。
    - **西風帶指數 (Westerly Index)**: 計算東西行航班的風力差值，量化西風帶強度。
- **飛行包絡線分析**: 繪製馬赫數 vs 高度圖，觀察民航機巡航特性。

### 3. 🔬 進階物理圖表深度解析

為了讓您更深入理解這些數據背後的物理意義，以下是對七張進階圖表的詳細解讀指南：

#### A. **`plot_d_value` (Geopotential Height Anomaly)**
這張圖揭示了**真實高度 (GPS)** 與 **氣壓高度 (Barometer)** 之間的差異，是判斷高空高/低壓系統的黃金指標。
*   **物理原理**: $D = \text{Alt}_{\text{Geom}} - \text{Alt}_{\text{Baro}}$
*   **如何看圖**:
    *   **🔴 紅點區 ($D > 0$)**: 代表 **高壓脊 (Ridge)** 或 **暖空氣**。在相同氣壓面下，暖空氣體積膨脹，真實高度會比標準高度高。通常伴隨好天氣。
    *   **🔵 藍點區 ($D < 0$)**: 代表 **低壓槽 (Trough)** 或 **冷空氣**。冷空氣收縮，真實高度會比標準高度低。通常伴隨不穩定天氣或鋒面通過。
    *   **應用**: 如果您看到整片都是藍點，代表新竹上空正受冷氣團或低壓帶控制。

#### B. **`plot_energy` (Specific Energy Height)**
這張圖展示了飛機的 **總機械能 (Total Energy)** 狀態，而不僅僅是高度。
*   **物理原理**: $E_s = h + \frac{V^2}{2g}$ （比能量 = 位能 + 動能）
*   **如何看圖**:
    *   這張圖通常會呈現一條或多條斜率一致的 **能量帶 (Energy Bands)**。
    *   **平滑的線條**: 代表飛機在進行高效率的能量管理 (例如連續爬升或連續下降 CDA)。
    *   **散亂的點**: 代表航管頻繁要求飛機改變速度或高度 (例如在空中盤旋 Hold 或梯級下降)，導致能量轉換不連續。

#### C. **`plot_density` (Air Density Profile)**
這張圖驗證了大氣密度隨高度 **指數遞減** 的物理定律。
*   **物理原理**: $\rho = \frac{P}{RT}$
*   **如何看圖**:
    *   **🔴 紅色虛線**: 代表標準大氣模型 (ISA) 的理論曲線。
    *   **彩色散點**: 代表利用 ADS-B 數據反推的 **實測空氣密度**。
    *   **觀察重點**: 如果實測點明顯 **低於** 紅線 (偏左)，代表今天高空空氣特別 **稀薄** (通常發生在夏天或高溫時)，這會影響飛機的升力與引擎推力性能。

#### D. **`plot_turbulence` (Vertical Turbulence Spectrum)**
這是一張 **直方圖 (Histogram)**，用來量化新竹上空的亂流強度。
*   **物理原理**: 統計所有航班的 **垂直速率震盪幅度**。
*   **如何看圖**:
    *   **正常情況**: 圖形應該像一座尖塔，絕大多數數據集中在最左側 (0~500 fpm 的平穩氣流)。
    *   **亂流特徵**: 觀察右側的 **長尾巴 (Long Tail)**。
    *   **🟠 橘色虛線**: 中度亂流門檻 (>2000 fpm 瞬時變化)。
    *   **🔴 紅色虛線**: 強烈亂流門檻 (>4000 fpm 瞬時變化)。
    *   **應用**: 如果右側尾巴很長且顏色很深，代表今天高空非常顛簸，搭飛機請務必繫好安全帶！

#### E. **`plot_contrail` (Contrail Formation Zone)**
如果您想知道今天抬頭會不會看到 **飛機雲 (凝結尾)**，看這張圖就對了！
*   **物理原理**: **Appleman Criterion (簡化版)**。當環境溫度低於臨界值，引擎排出的水氣會立即凝結成冰晶。
*   **如何看圖**:
    *   **🔵 藍色背景區 ($T < -50^\circ\text{C}$)**: **極可能區**。飛機雲容易形成且持久不散。
    *   **🟡 黃色背景區 ($-40^\circ\text{C} \sim -50^\circ\text{C}$)**: **可能區**。飛機雲可能形成，但較短暫。
    *   **🔴 紅色背景區 ($T > -40^\circ\text{C}$)**: **不可能區**。溫度太高，水氣無法凝結。
    *   **應用**: 如果大部分航班 (彩色點點) 都落在藍色區，趕快出門看天空吧！

#### F. **`plot_rssi_polar` (Antenna Coverage Pattern)**
這是一張 **極座標雷達圖**，用來檢視天線在 360 度方位的收訊效能。
*   **幾何原理**: 利用您的接收站座標與飛機座標計算 **方位角 (Bearing)** 與 **距離 (Distance)**。
*   **如何看圖**:
    *   **圓周 (Azimuth)**: 代表方位，N(北)、E(東)、S(南)、W(西)。
    *   **半徑 (Radius)**: 代表距離 (km)。點離圓心越遠，代表收訊距離越遠。圖中 **青色虛線** 標示了各方位的極限收訊邊界。
    *   **顏色 (Color)**: 代表訊號強度 (RSSI)。**紅色/黃色**最強，**深紫色**最弱。
    *   **應用**: 如果您發現圖形的某個方向 (例如東邊) 缺了一角或是半徑特別短，那就代表那個方向可能有建築物或地形 (如中央山脈) 遮蔽了訊號！

#### G. **`plot_rssi_vs_dist` (Signal Path Loss)**
這是一張 **距離衰減分析圖**，驗證無線電波在大氣中的傳播特性。
*   **物理原理**: **自由空間路徑損失 (FSPL - Free Space Path Loss)**。訊號強度與距離平方成反比 ($P \propto 1/d^2$)。
*   **如何看圖**:
    *   **X軸**: 距離 (km)。
    *   **Y軸**: 訊號強度 (RSSI)。
    *   **趨勢**: 點的分佈應該呈現 **向右下方傾斜** 的趨勢。
*   **工程分析心法**:
    1.  **驗證平方反比定律 (Inverse Square Law)**: 觀察數據點的 **天花板 (Upper Envelope)**。距離每增加一倍 (e.g. 50km -> 100km)，最高訊號強度理論上應衰減約 **6 dB**。若衰減過快，代表大氣吸收嚴重。
    2.  **檢測接收靈敏度 (Sensitivity)**: 觀察數據點的 **地板 (Floor)**。隨著距離增加，最低訊號強度會停留在某個數值 (e.g. -35 dBFS)，這就是系統的解碼極限。
    3.  **發現菲涅爾區遮蔽 (Fresnel Zone)**: 觀察趨勢線是否在特定距離區間 (e.g. 60-80km) 出現 **異常凹陷 (Dip)**，這通常代表該距離處有地形或建築物侵入無線電傳播通道。
    4.  **異常**: 如果在大距離 (>300km) 突然有一些 RSSI 很強的點 (異常高)，那可能是 **大氣波導 (Ducting)** 現象所致！

1. **環境配置**: 確保 `readsb` 正常運行並輸出 JSON。
2. **啟動紀錄器**:
   ```bash
   nohup ./scripts/recorder.sh > /dev/null 2>&1 &
   ```
   *註：腳本內建防呆機制，重複執行會自動阻擋。*

3. **停止與重啟紀錄器 (維護用)**:
   如果您修改了 `recorder.sh` 或想要重啟採集程序，請執行以下指令：

   - **尋找執行中的 PID**:
     ```bash
     ps aux | grep recorder.sh
     ```
   - **終止程序**:
     ```bash
     kill <PID>
     # 或者使用強力終止
     pkill -f recorder.sh
     ```
   - **確認已停止**:
     再次執行 `ps aux | grep recorder.sh` 確保無殘留程序，然後重新執行啟動指令。

4. **更新分析報告**:
   ```bash
   # 預設模式 (分析過去 24 小時)
   ./scripts/update_all.sh

   # 指定模式 (例如只分析過去 6 小時)
   ./scripts/update_all.sh 6
   ```
   *註：執行後會自動產生圖表、地圖並歸檔至 `reports/daily_archive/YYYY-MM-DD/`，最新圖表亦會保留於 `reports/` 供即時檢視。*
5. **歷史回顧與歸檔**:
   - **手動查詢特定日期 (如 2026-02-17)**:
     ```bash
     python3 scripts/dashboard.py --date 2026-02-17
     python3 scripts/mapper.py --date 2026-02-17
     ```
   - **自動歸檔昨日數據**:
     ```bash
     ./scripts/archive_yesterday.sh
     ```
     *建議將此指令加入 Crontab (例如每日 01:00) 以建立完整的歷史資料庫。*
    
   - **R 語言進階分析 (生成物理報告 txt)**:
     ```bash
     ./scripts/dashboard.R --date 2026-02-18 --start_hour 6 --end_hour 12
     ```
     *這將生成指定時段 (06:00-12:00) 的 ggplot2 圖表與詳細文字報告 (`report_YYYY-MM-DD.txt`)，包含西風帶強度、對流層頂預測等物理指標。*

6. **單機追蹤 (Single Aircraft Tracking)**:
   針對特定航班進行深入分析，判斷地形遮擋或飛行異常。系統會自動過濾雜訊、移除熱圖，並繪製詳細的航點數據 (時間/高度/速度)。
   ```bash
   # 查詢特定航班號 (支援大小寫)
   python3 scripts/mapper.py --callsign CI51 --hours 24

   # 查詢特定 Hex Code (最精確，適合找特定飛機)
   python3 scripts/mapper.py --hex 89905d --date 2026-02-17
   ```
   *特色功能：*
   - **斷線偵測**: 若訊號中斷超過 5 分鐘 (例如被山脈遮擋)，軌跡會自動斷開，不進行虛假連線，方便判斷訊號盲區。
   - **詳細標記**: 點擊軌跡上的圓點，可查看該點的精確時間與飛行狀態。

7. **自動化排程**:
   建議透過 `crontab -e` 設定每小時執行一次 `update_all.sh`，以維持最新觀測狀態。
