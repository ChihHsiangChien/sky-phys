在上一篇《ADS-B 數位觀察：分析桃園空域航線、高度與信號傳播特性》中，我們處理了基本的航跡數據。本篇將進入核心——大氣物理分析。透過 R 語言對 DAPs 數據的處理，我們能將每架飛機轉化為高空探空儀，重建出即時的大氣剖面。

1. 數據清洗：確保物理分析的準確性

在進行物理計算前，必須篩選出可靠的樣本。在 dashboard.R 中，我設定了嚴格的過濾條件，確保分析的是處於穩定巡航狀態的噴射機，排除低速或起降階段的干擾：

# 篩選高速、高空且具備完整參數的樣本
df <- df %>%
  filter(!is.na(tas), !is.na(mach), !is.na(alt)) %>%
  filter(tas > 100, mach > 0.3, alt > 5000)

2. 熱力學推導：從馬赫數找回氣溫

高空感測最困難的是獲取準確的「靜溫」(Static Air Temperature)。我們利用真空速 (TAS) 與馬赫數 (Mach) 的比值來推算音速，進而求得溫度。根據單位換算，節 (knots) 與絕對溫度的關係常數約為 38.945。

# 物理計算：音速與溫度
df <- df %>%
  mutate(
    speed_of_sound = tas / mach,
    temp = (speed_of_sound / 38.945)^2 - 273.15
  )

對流層頂 (Tropopause) 的自動偵測

腳本中還包含了一套簡單的邏輯來預測對流層頂。如果在觀測最高度溫度仍持續下降，代表對流層頂位於更高空：

analyze_tropopause <- function(df) {
  top_alt <- max(df$alt, na.rm = TRUE)
  min_temp <- min(df$temp, na.rm = TRUE)
  return(sprintf("對流層頂預測: 目前觀測最高 %.0f ft 溫度仍下降至 %.1f°C", top_alt, min_temp))
}

3. 風場分析與西風指標 (Westerly Index)

利用飛機的地速 (GS) 與真空速 (TAS) 的差異，我們可以計算航向上的風分量。這對於觀察噴射氣流 (Jet Stream) 的強度非常有幫助。

# 計算高空西風帶強度指標
wind_diff <- avg_wind_east - avg_wind_west # 往東順風與往西逆風的差值

當順風分量超過 100 節時，系統會自動發出強風警報。透過這種方式，我們可以量化「西風帶」對跨太平洋航線的實際影響。

4. D-Value 分析：氣壓偏差的實測

這是腳本中另一個進階分析。飛機回傳的高度有兩種：氣壓高度 (alt) 與 GPS 幾何高度 (alt_geom)。兩者的差值稱為 D-Value。

# 計算 D-Value：反映大氣壓與標準大氣的偏差
df <- df %>% mutate(d_value = alt_geom - alt)

這能告訴我們當前空域的氣壓是否偏離標準大氣。正值代表當地氣壓高於標準（高壓區），負值則代表低壓區。

5. 高階建模：空氣密度與能量高度

利用標標準大氣模型，我們推導出空氣密度與總比能 (Specific Energy Height)：

# 計算總比能 (特定能量高度)
df <- df %>%
  mutate(
    v_ms = tas * 0.514444,
    specific_energy = h_m + (v_ms^2) / (2 * g)
  )

這個指標代表了飛機的「總能量」，是評估飛行效率與性能包絡線的重要指標。
